# AI 设置页 API Key 配置设计

## 背景

当前 AI 设置页只支持模型、最大 Token 和温度配置，后端 `api/chat.cjs` 仅从环境变量 `DEEPSEEK_API_KEY` 读取密钥，不支持用户在界面中自行填写。

## 目标

在 AI 设置面板中新增 `API Key` 输入能力，允许用户在前端本地保存并在请求时传给后端使用。

## 方案

采用“前端本地存储 + 请求透传 + 后端优先使用请求值”的方案：

- 设置页新增 `API Key` 输入框，支持显示/隐藏。
- `apiKey` 纳入现有 `aiSettings`，沿用 `localStorage` 持久化。
- 前端流式聊天请求新增 `apiKey` 字段。
- 后端调用 DeepSeek 时优先使用请求中的 `apiKey`，未提供时回退到 `.env` 中的 `DEEPSEEK_API_KEY`。
- 设置页当前配置区仅展示“已配置/未配置”，不展示明文密钥。

## 边界

- 本次不新增“测试连接”按钮。
- 本次不新增多厂商配置或独立凭证中心。
- 本次不做加密存储，按浏览器本地配置处理。

## 验证

- 设置页可录入并保留 `API Key`。
- 前端构建通过。
- 现有聊天请求结构兼容新增字段。
