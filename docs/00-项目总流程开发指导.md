# React Playground 项目总流程开发指导

## 一、开发顺序指导

### 阶段1：基础环境搭建（必须优先完成）
```
1. main.tsx          - 应用入口点
2. App.tsx           - 根组件
3. vite-env.d.ts     - TypeScript 环境声明
```

**依赖关系**：
- `main.tsx` 依赖 `App.tsx`
- 所有 TypeScript 文件依赖 `vite-env.d.ts`

### 阶段2：核心工具和状态管理（基础设施）
```
4. utils.ts          - 工具函数（压缩、解压、语言识别）
5. files.ts          - 默认文件配置
6. stores/fileStore.ts    - 文件状态管理
7. stores/themeStore.ts   - 主题状态管理
8. stores/index.ts        - 状态管理统一导出
```

**依赖关系**：
- `fileStore.ts` 依赖 `utils.ts` 和 `files.ts`
- `stores/index.ts` 依赖所有 store 文件
- 后续所有组件都依赖这些基础设施

### 阶段3：AI 服务层（独立模块）
```
9. services/optimizedAI.ts  - AI 服务实现
10. stores/aiStore.ts       - AI 状态管理
```

**依赖关系**：
- `aiStore.ts` 依赖 `optimizedAI.ts` 和 `fileStore.ts`
- AI 功能相对独立，可以并行开发

### 阶段4：基础组件开发（UI层）
```
11. components/Message/index.tsx     - 消息显示组件
12. components/Header/index.tsx      - 头部组件
13. ReactPlayground/index.tsx        - 主容器组件
```

**依赖关系**：
- `Header` 依赖 `fileStore` 和 `themeStore`
- `ReactPlayground/index.tsx` 依赖 `themeStore`

### 阶段5：编辑器模块（复杂组件）
```
14. components/CodeEditor/Editor/ata.ts           - TypeScript 自动类型获取
15. components/CodeEditor/Editor/index.tsx        - Monaco 编辑器封装
16. components/CodeEditor/FileNameList/FileNameItem.tsx  - 文件标签项
17. components/CodeEditor/FileNameList/index.tsx  - 文件标签列表
18. components/CodeEditor/index.tsx               - 编辑器主组件
```

**依赖关系**：
- `Editor/index.tsx` 依赖 `ata.ts`
- `FileNameList/index.tsx` 依赖 `FileNameItem.tsx` 和 `fileStore`
- `CodeEditor/index.tsx` 依赖上述所有编辑器子组件

### 阶段6：预览模块（编译系统）
```
19. components/Preview/compiler.worker.ts  - Web Worker 编译器
20. components/Preview/index.tsx           - 预览组件
```

**依赖关系**：
- `compiler.worker.ts` 依赖 `fileStore` 类型定义
- `Preview/index.tsx` 依赖 `compiler.worker.ts` 和 `fileStore`

### 阶段7：AI 功能模块（高级功能）
```
21. components/AISettings/index.tsx    - AI 设置组件
22. components/AIAssistant/index.tsx   - AI 助手主组件
```

**依赖关系**：
- `AISettings` 依赖 `aiStore` 和 `themeStore`
- `AIAssistant` 依赖 `aiStore`、`themeStore` 和 `AISettings`

### 阶段8：模板文件（可选）
```
23. template/main.tsx    - 模板主文件
24. template/App.tsx     - 模板应用组件
```

**依赖关系**：
- 这些是用户项目的模板文件，相对独立

## 二、整体开发步骤

### 阶段1：环境配置与基础搭建（1-2天）

#### 关键任务
1. **初始化项目**
   ```bash
   npm create vite@latest react-playground --template react-ts
   cd react-playground
   npm install
   ```

2. **安装核心依赖**
   ```bash
   npm install zustand @monaco-editor/react @babel/standalone
   npm install fflate file-saver jszip lodash-es
   npm install antd @ant-design/icons allotment
   npm install copy-to-clipboard classnames
   ```

3. **配置开发环境**
   - 配置 TypeScript (`tsconfig.json`)
   - 配置 Vite (`vite.config.ts`)
   - 配置 ESLint (`eslint.config.js`)

4. **创建基础文件结构**
   ```
   src/
   ├── main.tsx
   ├── App.tsx
   ├── vite-env.d.ts
   └── ReactPlayground/
       ├── stores/
       ├── services/
       ├── components/
       └── template/
   ```

#### 验证节点
- ✅ 项目能正常启动
- ✅ TypeScript 编译无错误
- ✅ 基础路由和样式正常

## 四、常见问题和解决方案

### 问题1：Monaco 编辑器加载失败
**原因**：CDN 资源加载问题或配置错误
**解决**：
```typescript
// 配置 Monaco 编辑器路径
import { loader } from '@monaco-editor/react';
loader.config({ paths: { vs: '/monaco-editor/min/vs' } });
```

### 问题2：AI 服务连接失败
**原因**：后端服务未启动或 CORS 配置问题
**解决**：
1. 确保后端 API 服务运行在 3001 端口
2. 检查 CORS 配置
3. 验证 EventSource 兼容性

### 问题3：文件状态同步问题
**原因**：Zustand 状态更新不及时
**解决**：
```typescript
// 确保使用正确的状态更新方式
set({ files: newFiles }); // ✅ 正确
files.push(newFile);      // ❌ 错误
```

### 问题4：预览窗口编译错误
**原因**：Babel 配置或 Web Worker 问题
**解决**：
1. 检查 Babel 插件配置
2. 验证 Web Worker 文件路径
3. 确认 import-map 配置正确
